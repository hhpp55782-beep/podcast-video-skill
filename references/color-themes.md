## ASS 颜色格式说明

ASS 字幕颜色是 `&HAABBGGRR&`（注意 BGR 顺序，不是 RGB）。换算：把 HEX `#RRGGBB` 倒过来写成 `&HBBGGRR&`。

- `#FFD700`（金黄）→ R=FF G=D7 B=00 → `&H00D7FF&`
- `#4ECDC4`（青绿）→ R=4E G=CD B=C4 → `&HC4CD4E&`

## speakers.json 规范

```json
{
  "Speaker 1": {"name": "漫游土豆", "color": "&H00D7FF&"},
  "用户988511": {"name": "丸子", "color": "&HC4CD4E&"}
}
```

- key = 逐字稿里的说话人原文（必须和 transcript.txt 完全一致）
- `name` = 显示名（可 AI 根据上下文起）
- `color` = 该说话人字幕颜色（ASS BGR），从色板按出现顺序取
